RAVEXIS CREW ROMANIA — proiect Android inițial

CE CONȚINE
- Aplicație Android nativă tip WebView, package: ro.ravexiscrewromania.app
- Interfața demonstrativă în assets (Acasă, Alătură-te, Evenimente, Galerie, Cont)
- Workflow GitHub Actions pentru construirea unui APK debug în cloud.

IMPORTANT
Aceasta este o versiune DEMO. Cererile sunt salvate local pe dispozitiv.
Autentificarea reală, rolul de administrator, baza de date online, încărcarea fotografiilor
și sincronizarea între utilizatori NU sunt implementate. Nu introduce parole reale.
APK-ul debug nu este semnat pentru publicare în Google Play.

CUM SE OBȚINE APK-UL
1. Încarcă întregul conținut al arhivei într-un repository GitHub nou.
2. Deschide fila Actions și rulează „Build RAVEXIS Android APK”.
3. La final, descarcă artifact-ul „RAVEXIS-CREW-ROMANIA-debug-APK”.
4. În arhivă se află app-debug.apk pentru instalare de test.

Nu este necesar un abonament Thunkable. GitHub Actions oferă minute gratuite în limitele
planului și politicilor contului; disponibilitatea depinde de cont. Nu este publicare Play Store.
